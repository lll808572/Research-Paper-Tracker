# Deep Research

Use this skill when the user needs:
- topic refinement
- literature review
- systematic comparison of papers
- research gap discovery
- hypothesis framing

## Workflow
1. Clarify topic and boundaries.
2. Break the topic into subthemes.
3. Build a comparison matrix:
   - source
   - problem
   - method
   - data
   - result
   - limitation
4. Identify patterns and disagreements.
5. Extract research gaps.
6. Propose promising research directions.

## Rules
- Never invent references.
- Mark unsupported ideas clearly.
- Distinguish evidence from inference.
- Prefer structured output over free-form narration.

## Outputs
- topic memo
- literature matrix
- gap analysis
- research question candidates
