# Academic Paper Reviewer

Use this skill when the user wants:

- peer review simulation
- harsh critique before submission
- reviewer-style scoring
- questions authors should answer

## Review dimensions

- significance
- originality
- soundness
- evidence quality
- clarity
- structure
- citation quality
- reproducibility

## Output

1. Summary
2. Strengths
3. Weaknesses
4. Major concerns
5. Minor concerns
6. Questions for authors
7. Recommendation
