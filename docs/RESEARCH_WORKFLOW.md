# Research Workflow

## Daily

1. 检查上次成功运行时间。
2. 检查遗漏区间。
3. 搜索最新论文和重要更新。
4. 获取元数据。
5. 论文去重。
6. 相关性和质量筛选。
7. 获取全文或标注摘要级分析。
8. 生成论文卡片。
9. 更新索引。
10. 更新日志。
11. 检查变更。
12. 提交到 GitHub。

## Weekly

1. 读取本周论文卡片。
2. 按研究方向分类。
3. 对比技术路线。
4. 识别交叉研究。
5. 总结趋势。
6. 推荐精读论文。
7. 提出研究问题。
8. 生成周报。

## Failure Recovery

- 记录失败原因。
- 不更新成功时间。
- 下次补检遗漏区间。
- 不重复生成论文卡片。
- Git 冲突时停止自动覆盖。
