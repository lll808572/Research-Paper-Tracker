## E. 来源使用原则

1. arXiv 用于发现最新研究。
2. OpenReview 用于追踪投稿和评审信息。
3. 正式会议或期刊官网用于核实录用状态。
4. Crossref 用于核实 DOI。
5. Semantic Scholar / OpenAlex 用于补充元数据。
6. 搜索结果不能代替论文全文。
7. 保留来源 URL 和访问日期。
